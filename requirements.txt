## Installation

### Standard Installation
```bash
pip install -r requirements.txt
```

### Development Installation
```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

### From Source
```bash
git clone <repository>
cd Buildathon
pip install -e .
```

## Platform Requirements

- **Python**: 3.14 or higher
- **OS**: Windows 10/11, macOS 10.15+, Linux (Ubuntu 20.04+)
- **RAM**: 4GB minimum, 8GB recommended
- **Storage**: 500MB for installation, 1GB for sample netlists

## Browser Requirements

- Chrome 90+
- Firefox 88+
- Edge 90+
- Safari 14+

## Notes

- All dependencies are pure Python (no C extensions required)
- NetworkX provides graph algorithms
- Streamlit handles web UI
- PyVis generates interactive visualizations
- No GPU required
