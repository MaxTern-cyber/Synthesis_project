# GitHub Profile README -- setup instructions

GitHub looks for a special repo named **exactly** the same as your username. Its README.md appears at the top of your GitHub profile (`github.com/MaxTern-cyber`).

## Step 1 -- Create the repo

1. Go to https://github.com/new
2. Repository name: **`MaxTern-cyber`** (must match your username exactly, case-sensitive)
3. Public
4. Check "Add a README file"
5. Click **Create repository**

GitHub will show a confetti animation -- that's the "special repo" recognition.

## Step 2 -- Replace its README with the content below

Click the pencil icon on the auto-generated `README.md` and paste the content from [`PROFILE_README_TEMPLATE.md`](PROFILE_README_TEMPLATE.md) (next to this file).

## Step 3 -- Pin `Synthesis_project`

On your profile page, click **"Customize your pins"** -> check `Synthesis_project` -> Save.
