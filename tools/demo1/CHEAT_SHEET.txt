📊 ANALYSIS FEATURES
───────────────────────────────────────────────────────────────────────────
  tool.detect_combinational_loops()
    → Finds cycles (unintended latches) - CRITICAL!

  tool.find_critical_paths(top_n=10)

  tool.trace_signal_path("signal_a", "signal_b")
    → Shows all paths between two signals

  tool.calculate_logic_depth()
    → Shows logic levels (may fail on sequential circuits)

💡 TIPS
───────────────────────────────────────────────────────────────────────────
• Use backward_cone to find root causes of bugs
• Use forward_cone to assess impact of changes
• Export cones for smaller, easier-to-view graphs
• The loops detected are often flip-flop feedback (normal in sequential)
• High fanout gates (>50) may have timing issues
• Open HTML files in browser for interactive exploration


🆘 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────
Q: "Gate not found"
A: Use verify_gate to check if it exists, or use signal name instead

Q: "No path found"
A: Signals may not be connected, or path is too long (increase cutoff)

Q: "Graph contains a cycle"
A: Normal for sequential circuits - flip-flops have feedback

Q: "Too many loops detected"
A: If >100 loops, may have real combinational loops (check non-FF gates)
